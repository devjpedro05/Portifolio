# Imagens do portfólio

Coloque sua foto profissional neste arquivo:

- `public/images/foto-perfil.jpg`

Coloque os ícones das redes sociais nesta pasta:

- `public/images/social/instagram.png`
- `public/images/social/linkedin.png`
- `public/images/social/github.png`
- `public/images/social/whatsapp.png`

Se algum arquivo não existir, o portfólio usa fallback automático:

- foto: placeholder premium
- redes sociais: `react-icons`
